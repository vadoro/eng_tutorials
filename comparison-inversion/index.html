신호어가 짝을 부른다

as … as, than, the … in, superior to, If we had known, Should you have, Only after … — 비교·가정법·도치 문제에는 늘 답을 정하는 작은 낱말이 있어요. 이 튜토리얼에서는 그 낱말을 신호어라고 불러요. 신호어는 정해진 짝을 불러요. as는 원급을, than은 비교급을, 맨 앞의 Had는 숨은 if를, 맨 앞의 Only after는 ‘조동사 + 주어’ 어순을요. 한국어는 ‘~보다 · 가장’을 붙일 뿐 낱말 모양이 그대로이고, 어순이 뒤집히는 도치도 없어서 영어의 짝이 낯설어요. 영상 아래에는 신호어를 바꾸면 문장이 다시 짜이는 신호어 스위치, 토익 Part 5 연습 문제, 퀴즈가 이어져요.

신호어 스위치

같은 문장에서 신호어만 바꿔 보세요. as … as를 than으로, If + 과거를 If + had p.p.로, 보통 어순을 Only after …로 바꾸면 문장 조각이 미끄러지며 다시 짜이고, 빈칸에 와야 할 짝이 바뀌어요. 후보를 하나 골라 빈칸에 넣으면 규칙 엔진이 후보마다 맞고 틀린 까닭과 몇 단계(① 신호어 · ② 짝 · ③ 함정)에서 지워지는지 알려 줘요. 문장의 틀(신호어 종류, 가정법인지)은 틀마다 데이터에 적어 둔 것이에요.

    한 문제씩 풀어요. 막히면 힌트를 누르세요. 3단계 풀이법(신호어 → 짝 → 함정)이 한 단계씩 열리고, 신호어와 주어 같은 단서에 색이 칠해져요. 답을 고르면 보기마다 모양과 맞고 틀린 까닭(몇 단계에서 지워지는지), 해석, 완성 문장의 발음이 나와요.

    영상 순서대로 나와요. 답을 고르면 바로 해설이 보여요. 그림 문제는 그림 속 문장 조각을 눌러도 돼요.

      핵심 정리

      한눈에 보는 신호어와 짝

      ① 문장 속 신호어를 찾고, ② 신호어가 부르는 짝(모양 · 낱말 · 어순)을 맞추고, ③ 비슷해 보이는 함정을 지워요.

      ① 신호어 (비교)② 짝예③ 함정
      as ___ as원급as light as · runs as efficiently asas more efficient as ×
      ___ than비교급 (-er · more)lighter than · more reliable thanmore lighter ×
      ___ + 비교급 + thanmuch · even · far · still · a lotmuch larger thanvery larger ×
      less ___ than원급less expensive thanless more expensive ×
      the ___ + of · in · among · ever최상급the largest order we have ever receivedthe larger … ever ×
      one of the + 최상급 ___복수 명사one of the largest suppliersone of the largest supplier ×
      The 비교급 …, the ___the + 비교급The sooner you register, the more you save.the most you save ×
      superior · inferior · prior · senior ___tofar superior to that of its competitorssuperior than ×
      ① 신호어 (가정법 · 도치)② 짝예③ 함정
      If + 과거, ___would + 원형If we had more staff, we would finish on time.will finish ×
      If + had p.p., ___would have + p.p.If we had known, we would have called you.had called ×
      If ___, + would + 원형과거형 (be동사는 were)If our budget were larger, we would …If … would be ×
      맨 앞 ___ + 주어 …, 주절Should + 원형 · Had + p.p. · Were + 보어Should you have any questions, … · Had we known, …If we known ×
      맨 앞 Only · Not until · Never · Rarely · Under no circumstances조동사 + 주어 + 동사Only after the review will we announce the results.… we will announce ×
      맨 앞 Not only (조동사가 없을 때)do · does · did + 주어 + 원형Not only did the campaign increase sales, …did … increased ×
      and so · neither ___ + 주어앞 절 동사에 맞는 조동사…, and so did the marketing team.and so was ×

      ① 비교

      원급 positive
      낱말의 기본 모양. as … as 사이에 와요. as light as · as efficiently as
      비교급 comparative
      둘을 비교하는 모양. 짧은 낱말은 -er, 긴 낱말은 앞에 more. 짝은 than. lighter · more reliable · better
      최상급 superlative
      셋 이상 가운데 ‘가장’. the -est · the most + 범위(of · in · among · ever). the lightest of the three
      비교급 강조 intensifier
      ‘훨씬’. much · even · far · still · a lot + 비교급. very는 원급만 꾸며요.
      라틴어 비교급
      -or로 끝나고 짝이 to예요. superior to · inferior to · prior to · senior to · junior to

      ② 가정법

      가정법 subjunctive · unreal conditional
      사실과 반대로 상상하는 문장. 동사를 한 칸 과거로 보내요.
      가정법 과거 2nd conditional
      지금 사실의 반대. If + 과거, would + 원형. If we had more staff, we would finish on time.
      가정법 과거완료 3rd conditional
      지난 일의 반대. If + had p.p., would have + p.p. If we had known, we would have called.
      직설법 조건문 1st conditional
      실제로 일어날 수 있는 일. If + 현재, will + 원형. If we hire more staff, we will finish on time.

      ③ 도치

      도치 inversion
      조동사(또는 be동사)가 주어 앞으로 나와 어순이 뒤집히는 것. 질문할 때의 어순과 같아요.
      if를 뺀 도치
      If you should have → Should you have · If we had known → Had we known · If I were → Were I. 이 셋뿐이에요.
      부정어 도치
      맨 앞에 Only after · Only when · Not until · Not only · Never · Rarely · Seldom · Under no circumstances → 조동사 + 주어. 조동사가 없으면 do · does · did를 데려오고 뒤의 동사는 원형.
      so · neither + 조동사 + 주어
      ‘~도 그래요 · ~도 안 그래요’. 앞 절의 동사가 일반동사면 do 쪽, be동사면 be동사, 조동사면 같은 조동사. …, and so did the marketing team.

      한국어와 다른 점

      비교는 조사, 영어는 낱말 모양
      한국어: 저것보다 가볍다 · 가장 가볍다(‘가볍다’는 그대로). 영어: lighter than · the lightest(낱말이 바뀌고 짝이 와요).
      상상해도 현재 모양
      한국어 ‘직원을 더 뽑는다면 끝낼 텐데’는 현재 모양이지만, 영어는 한 칸 과거로 → If we hired …, we would finish …
      복수 표시
      ‘가장 큰 업체 중 하나’에는 복수 표시가 없지만 영어는 one of the largest suppliers.
      어순은 그대로
      한국어는 ‘검토가 끝난 뒤에야 발표해요’처럼 강조해도 어순이 바뀌지 않아요. 영어는 Only after the review will we announce …처럼 조동사가 주어 앞으로 와요.

      무엇이 규칙 계산인가요? 영상 속 ✓·×와 실전 문제에서 지워지는 순서, 직접 해 보기의 채점, 신호어 스위치의 후보 판정과 풀이, 연습 문제의 힌트와 보기별 해설, 퀴즈 대부분의 정답은 모두 이 페이지의 규칙 엔진(assets/js/grammar.js)이 계산해요. 엔진은 ① 신호어가 만드는 자리(품사 · 강조어 · 짝 낱말 · 조동사 자리)에 맞는지 → ② 신호어가 부르는 짝(원급 · 비교급 · 최상급, 가정법의 시제, 도치 어순)과 맞는지 → ③ 이름난 함정(비교 표시 두 번, very + 비교급, superior than, if절의 would, If가 남은 도치, 조동사 뒤 과거형, 수 · 시제가 다른 조동사)인지 순서로 판정해요. 문제에 적어 둔 정답이 규칙 엔진과 다르면 브라우저 콘솔에 경고가 떠요.

      단순하게 줄인 부분도 있어요. 문장의 틀(어떤 신호어인지, 빈칸의 품사, 가정법인지 직설법인지, 맨 앞에 부정어가 있는지)은 엔진이 문장을 읽고 알아내는 것이 아니라 문제마다 데이터에 적어 둔 것이에요. 실제 영어에는 one of the larger cities처럼 비교급을 쓰는 말도 있어서 그런 보기는 넣지 않았고, 둘 가운데 하나를 고르는 the lighter of the two는 다루지 않았어요. 가정법은 시험 기준으로 판정해요. if + 현재 뒤의 would, if절의 과거형이 실제 과거 일을 말하는 경우(If he left at five, he will …), 혼합 가정법(If I had studied, I would be …), 가정법의 was, Were + 주어 + to부정사는 다루지 않았어요. Should 도치의 주절에는 명령문 · will · would가 모두 올 수 있어서 그 자리는 문제로 내지 않았어요. 부정어 도치는 only · not until · not only · never · rarely · seldom · under no circumstances만 다루고, no sooner … than · hardly … when · so + 형용사 + that 도치는 넣지 않았어요. 신호어 스위치에서 어색한 낱말 짝(less light 같은)은 빼 두었어요. 예문과 문제는 토익 형식을 본떠 직접 만든 것으로, 실제 시험 문제가 아니에요.

      음성 해설과 발음 듣기는 VoiceStudio로 미리 만든 합성 음성으로 읽어요(해설의 한국어는 젊은 여성 내레이터, 영어와 발음 듣기는 미국 여성 선생님 목소리). 놀이터에서 만든 문장처럼 파일이 없는 글은 브라우저에 들어 있는 음성(speechSynthesis)으로 읽고, 브라우저 음성은 기기에 따라 목소리가 달라요. 이 페이지는 영어 튜토리얼의 한 꼭지예요. 품사(T02)와 시제(T04)를 먼저 보면 더 쉬워요.
